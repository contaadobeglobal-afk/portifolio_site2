# Preview sync

This package's public portfolio layer was rebuilt from the approved Anima Estudio V2 preview as the visual source of truth.

Synced public elements:
- Header/navigation and active section behavior
- Hero copy and editorial spacing
- Moving capabilities strip with centered symbols
- Six-project portfolio structure (3 primary + 3 complementary)
- 9:16, 3:4, 1:1 and 16:9 media treatment
- Project hover/cursor behavior
- About/expertise section including video editing, print/editorial and AI in the creative process
- CTA and footer hierarchy
- Individual project pages using the same case visual language
- 3:4 carousel support for social projects
- Favicon and Anima icon assets

The Supabase-backed admin remains separate from the visual preview layer and supplies the real project content in production.
