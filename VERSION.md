# Anima Estudio V2 — Final

This package aligns the public Next.js project with the approved V2 portfolio direction:

- six featured projects on home (three primary + three complementary);
- native 9:16, 3:4, 1:1 and 16:9 layouts;
- individual project pages;
- carousel presentation mode for multi-piece social projects;
- video / motion support;
- editorial and print positioning;
- AI explicitly positioned as part of the creative process;
- Anima favicon/icon SVG assets;
- Supabase media_mode field and admin selector;
- editorial cursor interaction on desktop.
